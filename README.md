# AI Music Assistant Downloads

This repository is a public, releases-only download channel for approved AI Music Assistant artifacts.

## Allowed public content

- Approved compiled installers
- Checksums
- Updater metadata
- Public release notes and installation guidance

## Never stored here

- Source code or private repository history
- Credentials, tokens, signing material, internal diagnostics, or user data
- Audio, FL Studio projects, metadata libraries, or other proprietary assets

Assets are published only by the protected release workflow after its repository-boundary, tag, version, checksum, and allowlist checks pass.
